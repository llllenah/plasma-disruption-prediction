# Фінальна здача — модель тривоги без фізики і без підказок симулятора

На кожному кроці 5 мс отримує покази 100 приладів і повертає ймовірність зриву від 0 до 1.
Потрібен лише `numpy`.

| файл | що це |
|---|---|
| `toksym.json` | маніфест: точка входу `model.py`, файли, залежність `numpy` |
| `model.py` | клас `Model`: `start_shot(meta)`, `predict(t, channels)` |
| `features.py` | онлайн-розрахунок 61 ознаки з сирих каналів (крок за кроком, лише минуле) |
| `weights.npz` | дві голови градієнтного бустингу (по 250 дерев) у вигляді масивів numpy |
| `config.json` | ознаки кожної голови, вага `w = 0.3`, згладжування `ema = 0.1` |

## Як рахує

```
100 приладів ─► features.py: nan → останнє значення; EMA 50 мс / 250 мс / 1 с, тренди, максимуми на плато
            ├─► голова A (57 ознак): «гасіння ≤ 0,1 с»  — передвісник
            └─► голова B (60 ознак): «гасіння ≤ 4,5 с»  — рання тривога
                p = max(A, 0,3·B);  на запрограмованому спаді струму p = 0;  EMA (0,1/крок) → бігучий максимум
```

**Ознаки:**
- фаза розряду за уставкою струму (частка від максимуму, спад, розгін);
- EMA і тренди: центральна хорда / уставка густини, центр SXR і ECE, Dα, середньоквадратичне Мірнова, сідлова петля;
- 15 сирих каналів;
- частота піків Dα, просідання Te і SXR;
- команди актуаторів (клапан неону, накопичений неон, нахил уставки густини);
- **детектор передвісника:** енергія швидкої складової сідлової петлі й котушок Мірнова за 20 / 50 мс і швидкість її росту.

**Чого немає (свідомо):**
- формул шпаргалки (f_GW, q95, β_N, P_rad/P_in, λ, константи JET), навіть як проксі;
- мітки сценарію з `meta`;
- таймерів від подій програми.

## Навчання

- 4500 розрядів `toksym gen` (3000 звичайних + 1500 `--shift`), окремі сиди.
- Мітки — лише з `shots.csv`, за моментом гасіння.
- Беремо кожен 4-й крок, за 2 с до гасіння — кожен 2-й.
- Виключено:
  - спонтанні зриви та контакт зі стінкою;
  - запрограмований спад.
