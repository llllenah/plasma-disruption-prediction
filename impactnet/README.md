# ImpactNet — вклад механізмів у зрив плазми

Нейромережа, яка на кожному кроці 5 мс за **100 приладами** симулятора каже:
- **наскільки небезпечно зараз** — загальний ризик λ і ймовірність зриву на 0,1 / 0,3 / 1 с;
- **через що** — частка кожного з 5 механізмів (сума рівно 100 %).

Механізми: **Грінвальд** (густина), **q95** (кінк), **радіація**, **Тройон** (βN), **інші** (locked mode тощо).

---

## 1. Склад теки

| файл | що це |
|---|---|
| `impact_net.npz` | ваги для інференсу на **numpy** (потрібен лише numpy) |

| `q95_form.json` | форма плазми (κ, δ) з котушок і петель потоку для q95 |

## 2. Як запустити

```python
from impactnet import ImpactStep
st = ImpactStep()                    # новий об'єкт на КОЖЕН розряд (у мережі є пам'ять)
for channels in kroky_rozryadu:      # dict «ім'я приладу → число», nan = прилад відмовив
    out = st.step(channels)
    out["share_pct"]    # {'greenwald': 81.0, 'q95': 0.0, 'radiation': 19.0, 'troyon': 0.0, 'other': 0.0}
    out["risk"]         # ризик кожного механізму, 0…1
    out["risk_total"]   # λ — загальна інтенсивність зриву, 1/с
    out["p_disrupt"]    # {0.1: …, 0.3: …, 1.0: …} — імовірність зриву на горизонті, с
    out["drivers"]      # f_GW, q95, frad, βN, пораховані з приладів
```

Цілий файл: `python impactnet.py measured.csv out.csv` (тут потрібен ще pandas).

### У замкненому контурі з симулятором дій (`fusion_sim_client`)
```python
st = ImpactStep()
with FusionSim("jet", "generated:1:0") as sim:
    names = sim.program()["channel_names"]
    while True:
        s = sim.step()
        if s["status"] != "Running" or s["t_tq"] is not None:
            break
        out = st.step(dict(zip(names, s["channels"])))
        # порадник: головний механізм = max(out["share_pct"]), запас до межі — з out["drivers"]
```

## 3. Що означають виходи

Мережа має **рівно 5 вихідних нейронів**, по одному на механізм. Усе інше виводиться з них точно,
за формулою ризику самого симулятора:

- нейрон k дає ризик механізму **rₖᵖ**, де rₖ = σ((xₖ − cₖ)/wₖ + поправка мережі), p = 3 (для «інших» p = 1);
- **вклад** Cₖ = −log(1 − rₖᵖ);
- **частка** share_pctₖ = 100 · Cₖ / ΣC — сума рівно 100 %;
- **загальний ризик** λ = 1 − e^(−ΣC) = 1 − Π(1 − rₖᵖ) — та сама формула, що в симуляторі;
- **імовірність зриву за h с**: 1 − e^(−λh). Це нижня оцінка, якщо λ не зміниться: перед зривом λ росте.

Чому частки коректні: λ — добуток «конкуруючих ризиків», тож після логарифма вклади механізмів
складаються. Cₖ/ΣC — це ймовірність, що зрив, якщо він стався зараз, спричинив саме механізм k.

**Важливо:** при малому λ частки — шум. 97 % «інших» при λ = 0,0006 означає «ризику немає».
Тому частки завжди читаються разом з `risk_total`.

## 4. Як побудована

```
100 приладів ──► препроцесинг (drivers.py) ──► 218 входів
                 • nan → останнє значення + маска відмови (100)
                 • 18 фізичних величин з методички: f_GW, q95, κ/δ-форма, βN, P_rad/P_in, W, dW/dt,
                   τE (0D-баланс), τ98 (IPB98), H98, поріг L–H (Мартін), запас P_in/P_LH, Te (ECE),
                   опір Спітцера, nτT (Лоусон), дебаївська довжина
                 • asinh-стиснення хвостів + робастна нормалізація (медіана/IQR), обрізання ±8
       ──► MLP (218 → 96)
       ──► 4 причинні згорткові блоки (ядро 3, дилатації 1/2/4/8 → бачать 31 крок = 155 мс):
           швидкі передвісники
       ──► GRU (128): коротка пам'ять розряду (від мс до ~1 с, chrono-ініціалізація гейта)
       ──► LayerNorm ──► Linear(128 → 5) + фізичне априорі (xₖ − cₖ)/wₖ
```

**Фізичне априорі.** Кожен нейрон прив'язаний до свого драйвера: f_GW, 2,2/q95, P_rad/P_in, βN/2,8.
Пороги c і ширини w стартують з формули симулятора і довчаються. Голова стартує з нулів, тому
**необучена мережа = чиста фізика**, а мережа вчить лише поправки на шум, затримки й калібрування
приладів.

Вивчені пороги (старт → після навчання):

| | Грінвальд f_GW | кінк 2,2/q95 | радіація P_rad/P_in | Тройон βN/2,8 |
|---|---|---|---|---|
| c | 1,00 → 1,035 | 0,90 → 0,910 | 0,80 → 0,842 | 0,85 → 0,884 |
| w | 0,08 → 0,118 | 0,05 → 0,056 | 0,08 → 0,098 | 0,06 → 0,061 |

Фізика лишилась фізикою; ширини трохи зросли, бо драйвери з приладів шумніші за справжні.

**Інші рішення:**
- LayerNorm, а не BatchNorm: у потоковому режимі статистики батча немає;
- ортогональні рекурентні ваги;
- залишкові гілки згорток стартують як тотожність.

## 5. Дані й мітки

- **Дані:** 2500 розрядів `toksym gen` (звичайний режим і shift), окремі сиди. Val — 200 розрядів,
  test — 200 розрядів, яких мережа не бачила.
- **Вхід мережі:** лише 100 приладів, як на заліку.
- **Мітки:** справжні ризики механізмів на кожному кроці. Рахуються з **істинного стану плазми**
  (колонки `--extras`) за формулою симулятора: λ = 1 − Π(1 − rᵢ³)(1 − r_lm), rᵢ = σ((xᵢ − cᵢ)/wᵢ).
  Розклад збігається з λ симулятора до 10⁻⁶. Істинний стан — лише для міток, на вхід не йде.
- **`shots.csv`:** рядки беруться лише до моменту запуску зриву і без запрограмованого спаду
  (там симулятор не кидає «кубик»).
- **Втрата:**
  - величини ризику — в лог-шкалі, щоб розрізняти 10⁻⁴ і 10⁻²;
  - частки — з вагою λ, щоб не форсувати шум при нульовому ризику.
- **Навчання:** вікна 3,2 с з прогрівом 0,64 с; AdamW + OneCycle; 40 епох; RTX 4090 (~6 хв).

## 6. Результати (test, 200 розрядів)

| | **ImpactNet** | MLP без пам'яті (еталон) |
|---|---|---|
| R² загального ризику λ, звичайний режим | **0,996** | 0,974 |
| R² λ, shift | **0,966** | 0,951 |
| похибка часток при λ > 0,1 (звичайний / shift) | **0,1** / 3,3 п.п. | 0,6 / 2,5 п.п. |
| домінуючий механізм при λ > 0,1 (звичайний / shift) | **100 %** / 97 % | 99,5 % / 98,6 % |
| механізм у момент запуску зриву | **49 / 49** | 49 / 49 |
| пуассонівська правдоподібність зривів (справжня λ: −0,699) | **−0,688** | −0,700 |
| очікувано / фактично зривів | 47,3 / 49 | 47,9 / 49 |

Мережа пояснює фактичні зриви так само добре, як справжня формула симулятора.

## 7. Швидкість

Крок «100 колонок → усі виходи» на numpy, одне ядро:

| де | p50 | p99 | макс | кроків > 5 мс |
|---|---|---|---|---|
| ноутбук | 0,61–0,66 мс | 1,3–2,0 мс | 1,8–3,3 мс | 0 |
| сервер (RunPod) | 0,51 мс | 0,66 мс | 3,6 мс | 0 |

У бюджет 5 мс вкладаємося із запасом. Numpy-версія збігається з PyTorch до 10⁻⁴ п.п.

## 8. Навчання без міток λ (як на реальному реакторі)

На реальній машині λ немає, є лише сигнали і момент зриву. Ту саму мережу вчили лише за моментами
зривів (пуассонівська правдоподібність Σ log λ(t_зриву) − ∫λ dt), без жодної колонки істинного стану:

| варіант | R² λ (звичайний / shift) | домінуючий механізм при λ > 0,1 | механізм у момент зриву |
|---|---|---|---|
| з мітками λ (основна) | 0,996 / 0,966 | 100 % / 97 % | 49/49 |
| **лише моменти зривів + фізичне априорі** | 0,948 / 0,796 | 99 % / 90 % | **49/49** |
| моменти + причина зриву, **без** априорі | 0,660 / 0,540 | 77 % / 66 % | 41/49 |

**Висновок:** λ відновлюється без розмітки, а механізми розрізняються **тільки завдяки фізичному
априорі**.

## 9. Обмеження

- **Це не сигналізація.** Як будильник ImpactNet слабка (об'єм 0,77), але й справжня λ дає лише 0,78.
  Зрив — кидок кубика, і тихі розряди теж підходять до межі. «Зрив за 30 мс» ловить модель тривоги
  (v8 / `submission_clean`), бо бачить передвісник після кидка. ImpactNet відповідає на «наскільки
  небезпечно і чому».
- **Тройон у даних не спрацьовує жодного разу.** Нейрон Тройона тримається на фізичному априорі.
- **Фонова підлога λ** (0,005 + r_lm, спонтанні зриви) на механізми не розкладається.
- **Shift (DT-паливо, інше поле):** частки трохи гірші, ніж у звичайному режимі. Більше даних
  уже раз це покращило.
- **Точно — для симулятора.** На реальному токамаці межі ті самі за фізикою, але пороги й форму
  треба довчати (див. розд. 8).
